# Gauto 3.0.0 — Living Island

**Gauto** — полностью независимое Android-приложение, которое помогает не стопаться
на мелочах и прокачивать навык разработки через автоматические правила личной жизни.

- Домашние дела → **закрывает YouTube**, TikTok и Instagram через сервис доступности.
- Сон → **монохромный экран**, тишина и малая яркость.
- Фокус → сессии 25/50 минут с блокировками и отчётом.
- Привычки, стрики, xp и «уровень разработчика».
- 16 готовых наборов / 64 правила, включая «сон без залипания» и «глубокий код».

---

## Living Island 3.0

Никакого нижнего бара. Внизу по центру живёт **плавающая капсула-остров**:

- **Максимум движения** — пружинный веер из 5 категорий с настоящим stagger-появлением
  (каждый лепесток вылетает с задержкой 48 мс и складывается в обратном порядке),
  волна раскрытия, wobble лепестков, два слоя дрейфующих частиц с хвостами,
  дыхание капсулы, пульсирующее ядро и тактильный отклик при раскрытии.
- **Живая карусель статусов** — каждые 3 секунды капсула показывает следующую плашку:
  активное правило → уровень/xp → стрик и привычки → завершённые фокус-сессии →
  статус синхронизации → последнее событие. Переход — вертикальный slide + fade.
- **Анимированный логотип** — `GautoAnimatedLogo`: капсула с пятью дышащими лепестками
  и пульсирующим ядром. Живёт в шапке и внутри острова, реагирует на активную категорию.
  Статичные файлы: `branding/gauto_logo.svg` / `.png`, `ic_launcher`, `ic_gauto_logo`,
  `ic_gauto_foreground`.
- **Material You** — на Android 12+ цвета поверхностей, акцентов и лепестков берутся
  из обоев (`dynamicDarkColorScheme`); на Android 11 остаётся фирменная палитра.
- **Живость настраиваемая** — `спокойно / обычно / максимум` в настройках; амплитуда
  частиц, wobble, дыхания и свечения реально меняется.

Top App Bar: живой логотип, `Gauto · <вкладка>`, поиск и уведомления с бейджем.

## Синхронизация с ПК

Полностью локальная, **без облака, аккаунта и токена**:

- телефон поднимает HTTP-сервер `GautoSyncService` на `:8765` и UDP-поиск на `:8766`;
- `GET /api/ping`, `GET /api/state`, `POST /api/state`, заголовок `X-Gauto-Pin`;
- один JSON: правила, привычки, фокус-сессии, настройки, события и `updatedAt`;
- побеждает более свежее состояние; PIN показывается в настройках телефона.

ПК-клиент: **[windows/gauto-desktop](windows/gauto-desktop/README.md)** — PySide6, тот же
Living Island (stagger, волна, анимированный логотип, карусель статусов, системный акцент
Windows), новая иконка, трей, автозапуск и автоматическое обнаружение телефона.

```bat
cd windows\gauto-desktop
pip install -r requirements.txt
python app.py
```

## Разрешения

Полноэкранная панель не закроется, пока не выданы спецвозможности, оверлей, изменение
системных настроек, точные будильники, уведомления и «Не беспокоить». **Без root,
прошивок и обязательного ADB.**
