# Gauto 4.0.0 — 4D Living Island + настоящий будильник

**Gauto** — единое приложение для подъёма, таймеров, напоминаний, правил,
привычек и фокуса. Всё в одном визуальном языке Living Island.

## Главное: будильник без откладывания

**На полноэкранном оверлее нет кнопок «Отложить», «Ещё 10 минут» и вообще snooze.**
Сигнал прекращается только осознанным долгим подтверждением **«Я встал»**
(или «Готово» для таймера / «Принято» для напоминания). Назад заблокирован.
Есть честный авто-стоп через N минут — он завершает сигнал и помечает пропуск,
а НЕ переносит будильник.

Настройки круче системного: время и дни, 5 мелодий (собственный синтезатор
`AudioTrack` с `USAGE_ALARM`), нарастание громкости, вибрация, «рассвет» за N минут
с плавным подъёмом яркости и снятием ч/б слоя, яркость пробуждения, снятие DND
и автоматическая разблокировка приложений после подтверждения.

## Единый UI: 8 категорий из островка

Веер островка: **Главная · Будильник · Таймеры · Правила · Привычки · Фокус ·
Напоминания · Настройки**. Те же карточки, чипы, градиенты, анимированный логотип
и карусель статусов на всех экранах.

## 4D

`Gauto4DBackdrop`: `cameraDistance` + `rotationX/Y` + масштаб (три оси глубины)
и **время как четвёртая ось** — фаза дня и фаза анимации управляют наклоном,
цветом и скоростью четырёх колец. Плюс stagger-веер, волна раскрытия, 42 частицы,
дыхание капсулы, тактильный отклик и настройка «живость». Material You на Android 12+.

## Разные блокировки

`BlockMode`: приложения · сон · фокус · таймер · **до подъёма** · напоминание.
Пока будильник не подтверждён, все отвлекающие приложения закрываются сервисом
доступности; критичные системные экраны не трогаются.

## Таймеры, звуки, эффекты

Пресеты 5/10/25/50 минут, обратный отсчёт, звук окончания, авто-стоп, блокировка
на время. Напоминания по времени и дням. Общий оверлей для всех трёх типов событий.

Взято лучшее из GSYNK и прокачано: точные будильники, `ToneSynth` → собственный
`AlarmRinger` с нарастанием, `Haptics` с `USAGE_ALARM`, DND, gradual brightness,
жидкие окна → 4D-морфинг островка.

## ПК

`windows/gauto-desktop/` — PySide6, те же 8 категорий, 4D-кольца, системный акцент
Windows, трей, автозапуск и LAN-синхронизация (`GautoState` schema 2: правила,
привычки, фокус, будильники, таймеры, напоминания, настройки, события).

```bat
cd windows\gauto-desktop
pip install -r requirements.txt
python app.py
```
