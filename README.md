# GAUTO 1.0.0 — автоматизация личной жизни

**GAUTO** — полностью независимое Android-приложение, которое помогает не стопаться
на мелочах и прокачивать навык разработки через понятные правила личной жизни.

- Когда нужно делать домашние дела — **закрывает YouTube** и соцсети.
- Когда пора спать — делает экран **монохромным**, убирает уведомления и яркость.
- Когда нужно работать — включает **фокус-сессию** с блокировками.
- За выполнение дел начисляет **xp**, стрики и «уровень разработчика».

Приложение портретное, интерфейс на русском, построен на **Material 3 с нижней
навигацией**: 5 вкладок, панель 80 dp, сверху заголовок вкладки, профиль, поиск и
уведомления. Все данные хранятся только на устройстве; сеть нужна лишь для
внутреннего автообновления.

## Возможности

| Блок | Что делает |
|---|---|
| Правила | дни, время, яркость %, громкость %, вкл/выкл, «Не беспокоить», ч/б слой, список блокируемых приложений |
| Блокировка | `AccessibilityService` ловит открытие YouTube/TikTok/Instagram и уводит на главный экран |
| Ч/б экран | сначала настоящий системный далтонизатор; если `WRITE_SECURE_SETTINGS` не выдан — монохромный оверлей через `SYSTEM_ALERT_WINDOW` |
| Привычки | 7 базовых привычек, стрики, недельная цель, xp |
| Фокус | Pomodoro 25/50 минут, блокировки на время сессии, отчёт |
| Статистика | уровень разработчика, прогресс, завершённые сессии, число блокировок |
| Наборы | 16 готовых сценариев / 64 правила: школа, домашние дела, сон, глубокий код, детокс, день релиза |
| Обновление | публичный GitHub API `GrapeGG-developer/GAUTO`, ETag, SHA-256 asset, сторож 200 мс, автозагрузка и системная установка |

## Разрешения

Полноэкранная панель не закроется, пока не выданы: спецвозможности, слой поверх
приложений, изменение системных настроек, точные будильники, уведомления и
«Не беспокоить». Дополнительно — батарея без ограничений и статистика
использования. Каждая карточка открывает свой системный экран.

**Без root, без прошивок, без обязательного ADB и без риска для POCO X8 PRO MAX.**

## Сборка

```bash
export JAVA_HOME=/opt/tools/jdk17
export ANDROID_HOME=/opt/tools/android-sdk
bash check.sh clean testDebugUnitTest lintDebug assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk` (`com.gauto.app.debug`).

## Обновление внутри приложения

Источник — обычный latest-релиз `https://github.com/GrapeGG-developer/GAUTO/releases`.
Токен в APK не вшит: используется публичный API с `If-None-Match`, запасной путь
через страницу релизов, проверка `digest` ассета и удаление временного APK после
установки.
