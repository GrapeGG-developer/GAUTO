# Gauto 5.0.0 — просто и по делу

Gauto помогает вовремя вставать, не отвлекаться и не забывать важное — без перегруженных экранов.

## Четыре раздела

| Раздел | Что увидишь |
|---|---|
| **Сегодня** | следующий подъём, что действует, одна привычка и 4 быстрых действия |
| **Будильник** | время, дни, звук, постепенный рассвет; без кнопки «Отложить» |
| **Правила** | расписания и блокировки; готовые планы раскрываются только по нажатию |
| **Ещё** | таймеры, напоминания, привычки, фокус, настройки, резервная копия |

На первом запуске коротко объясняется, что делать. Никаких восьми вкладок и длинных
списков готовых сценариев на главной.

## Главное правило будильника

На полноэкранном оверлее **нет «Отложить на 10 минут» и вообще snooze**.
Только долгое подтверждение **«Я встал»**. Назад заблокирован. Авто-стоп завершает
сигнал с отметкой пропуска, а не переносит его.

Есть пять звуков, нарастание громкости, вибрация, рассвет с постепенной яркостью,
снятие ч/б и «Не беспокоить» после подъёма.

## Быстрые действия на «Сегодня»

- **Фокус 25 мин** — начинает фокус-сессию и таймер.
- **Тишина 30 мин** — включает DND на полчаса, затем выключает автоматически.
- **Сон** — ч/б + тишина; на «Сегодня» появляется «Выключить режим сна».
- **Дела** — сразу открывает правила.

## Новое

- Виджет: следующий подъём, состояние, Фокус / Сон / Тишина.
- Резервная копия одним JSON-файлом.
- ПК-синхронизация по локальной сети, без облака и аккаунта.
- Будильники, таймеры и напоминания сохраняются между перезагрузками.
