# История Gauto

## 3.0.0 (versionCode 3) — «Living Island»

- **Material You:** `dynamicDarkColorScheme` на Android 12+, `LocalGautoAccents` для лепестков и фона, фирменный fallback на Android 11.
- **Анимированный логотип** `GautoAnimatedLogo`: дышащие лепестки, пульсирующее ядро, реакция на активную категорию; используется в шапке и в капсуле.
- **Максимум движения:** stagger-раскрытие каждого лепестка отдельным `Animatable` (48 мс), обратный порядок при схлопывании, волна раскрытия, wobble, 42 частицы с хвостами, усиленное свечение, тактильный отклик `HapticFeedbackType.LongPress`.
- **Живая карусель статусов** в капсуле: активное правило / уровень и xp / стрик / фокус-сессии / синхронизация / последнее событие, смена каждые 3 с через `AnimatedContent`.
- **Настройка «живость островка»** (`motionLevel`: спокойно / обычно / максимум) реально меняет амплитуду анимаций через `LocalGautoMotion`.
- **Gauto Desktop 3.0:** тот же Living Island на PySide6 — stagger, волна, анимированный логотип, карусель статусов и системный акцент Windows (`ColorizationColor`).
- Обновлены `GautoContractTest`, `UpdateLogicTest`, тесты ПК и заметки релиза.
- **Приёмка:** 26/26 unit-тестов Android, 8/8 тестов ПК, Lint 27 Warning / 0 Error / 0 Fatal, APK 61 112 694 байта, SHA-256 `5839631d91c72cbdafaafa9ab6a46d9278742abd1452a7d775aee4b2336d1a5f`.

## 2.0.0 (versionCode 2) — «Island UI + Gauto Desktop»

- **Новый логотип** `branding/gauto_logo.svg`: капсула-остров с пятью расходящимися лепестками-категориями; новые `ic_launcher`, `ic_gauto_logo`, `ic_gauto_foreground`.
- **Видимое имя приложения — `Gauto`** (пакет, классы и репозиторий не менялись, чтобы не ломать OTA).
- **Полностью переделана навигация:** скучный Bottom Navigation Bar удалён. Вместо него живой «островок» — плавающая капсула с активным правилом, пружинный веер из 5 категорий, `AnimatedContent`, бесконечное дыхание, параллакс фоновых спор, собственные геометрические глифы и обновлённая типографика/палитра.
- **LAN-синхронизация с ПК:** `SyncProtocol`, `GautoSyncService` (HTTP :8765 + UDP :8766), PIN, `GET/POST /api/state`, слияние по `updatedAt`, карточка в настройках с IP и PIN.
- **Gauto Desktop на PySide6:** тот же островок с анимациями, новая иконка, трей, автозапуск, UDP-поиск телефона, таблицы правил/привычек/фокуса и двусторонняя синхронизация.
- Добавлены `SyncProtocolTest`, обновлены `GautoContractTest` и `UpdateLogicTest`.
- **Приёмка:** 25/25 unit-тестов, 8/8 тестов ПК-протокола, Windows CI success (`Gauto.exe`), Lint 26 Warning / 0 Error / 0 Fatal, Android APK 61 079 926 байт, SHA-256 `01877a8b33bff799a16d5c7442a0b5500001be4ddf9b39ad1ce5dee1b3a25299`.

## 1.0.0 (versionCode 1) — первый релиз

- Отдельное независимое приложение Gauto, без зависимости от GSYNK.
- Material 3: нижняя навигация на 5 вкладок (80 dp), Top App Bar с профилем, поиском и уведомлениями.
- Перенесены правила яркости/громкости: дни, время, проценты, вкл/выкл, «Не беспокоить», восстановление после перезагрузки и возврат автояркости.
- Перенесены готовые автоматизации жизни и расширены до 16 наборов / 64 правил.
- Добавлены блокировка приложений через AccessibilityService, монохромный слой перед сном, фокус-сессии, привычки, стрики, xp и «уровень разработчика».
- Полноэкранная панель разрешений; без root/ADB/прошивок.
- Внутреннее автообновление из собственного репозитория: ETag, SHA-256, сторож 200 мс, автозагрузка и установка.
